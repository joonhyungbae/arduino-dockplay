작가의 영상을 여기에 넣습니다. 저장소에는 올라가지 않습니다.

```text
idle/   기다리는 동안 되풀이하는 영상. 여럿이면 이름 순서대로 돈다
play/   헤드셋을 내려놓으면 처음부터 트는 영상. 여럿이면 이름 순서대로 이어 튼다
```

넣고 나서 다시 켜면 목록(media.json)이 새로 만들어집니다. `./start.sh` 가 켤 때마다 대신 해 줍니다.

- H.264 mp4 가 가장 무난합니다. webm, mov, m4v 도 읽습니다.
- 순서를 정하려면 이름 앞에 번호를 붙입니다. `01-처음.mp4`, `02-끝.mp4` 처럼.
- 영상이 없으면 자리표시 화면이 대신 돕니다. 대기는 물결선, 본 영상은 20초짜리 화면입니다.
